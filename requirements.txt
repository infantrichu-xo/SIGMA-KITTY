# ffmpeg is NOT a pip package -- it's a system binary that music.py and
# tts.py both shell out to (via discord.FFmpegPCMAudio), used to build the
# audio Discord voice actually plays. Normally you'd install it separately
# and put it on PATH:
#   Windows: https://ffmpeg.org/download.html
#   macOS:   brew install ffmpeg
#   Debian/Ubuntu: sudo apt install ffmpeg
#
# On hosts without root/apt access (e.g. Wispbyte and other Pterodactyl-
# based panels), ffmpeg.py automatically falls back to imageio-ffmpeg above,
# which bundles a static ffmpeg binary via pip -- no manual install needed.
# Most Wispbyte "Python/discord.py" eggs already ship ffmpeg preinstalled
# too, so this fallback is just a safety net either way.
